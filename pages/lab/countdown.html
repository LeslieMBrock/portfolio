JavaScript Countdown Lab

This experiment demonstrates how JavaScript uses events, application state, and timing functions to create an interactive countdown.

Try the countdown

Choose 1–3600 whole seconds. Reset before changing duration while running or paused.

01:00

JavaScript is required to run this experiment.

How It Works

Event listeners
Button clicks and duration changes tell the timer what to do. Keyboard activation triggers the same button events.
Application state
The timer stores its mode, selected duration, remaining time, and active interval. Controls reflect whether it is ready, running, paused, or completed.
Timing functions
An interval refreshes the display. Remaining time comes from a deadline and the browser’s clock, so delayed callbacks do not add extra time.
Pause and resume
Pause saves the remaining time and clears the interval. Resume creates a new deadline from that saved time.
Managing intervals
Only one interval should run at once. Clearing it before a new run, on reset, and at zero prevents duplicate updates and keeps state and display synchronized.
