Neon Color Garden

A Little Color. A Little Chaos.

Explore color, creativity, and JavaScript interaction in this playful neon garden. Choose your colors, make a splash, and watch your canvas come alive!

Make a splash

Choose a neon color

Click or tap to place a paint dab. Drag to connect dabs into a stroke. Keyboard: Tab to the canvas, use arrow keys to move the white cursor, then press Space to paint. Clear removes paint; Reset also returns to Electric Pink and centers the keyboard cursor.

Your browser needs canvas support to display the painting.

JavaScript is required to paint in this garden.

How It Works

Event Listeners
Pointer events handle mouse, pen, and touch painting. Button clicks select colors or clear the canvas; keyboard events move the cursor and place paint dabs.
Color Selection
A variable stores the selected neon color. The palette shows which button is pressed, and each new dab or stroke uses that color.
Position and Coordinates
The program converts pointer coordinates into the canvas's fixed 900 by 500 drawing space. Arrow keys move a bounded keyboard position in that same space.
Dynamic Rendering
JavaScript draws round dabs and connected strokes with the canvas drawing API, adding a small neon glow. These marks appear immediately without reloading the page.
Application State
The game tracks the selected color, active pointer, previous stroke position, and keyboard position. Existing paint stays in the canvas pixels rather than a list of splats. Clear removes those pixels; Reset also restores the initial color and keyboard position.
