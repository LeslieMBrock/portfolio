Peace, Love & Code Arcade

A playful JavaScript experiment using projectile movement, collision detection, SVG graphics, and interactive messages.

How to play

Hold Launch with your mouse, touch, Space, or Enter, then release as a target stand approaches the dashed gold hit zone. The projectile takes a moment to arrive, so timing matters. Prefer no movement? Enable stationary mode and select a target directly with a click, tap, or keyboard.

0 / 3 targets

JavaScript is required to play this experiment.

How It Works

Event Listeners
Mouse, touch, and keyboard interactions allow visitors to control the slingshot. JavaScript listens for these actions and responds by updating the game.
Projectile Movement
When the projectile is released, JavaScript calculates its movement and updates its position over time, creating the effect of a moving object.
Collision Detection
The game checks whether the projectile reaches an SVG target. When a collision is detected, JavaScript identifies the target and triggers the corresponding response.
Application State
JavaScript keeps track of the game's current condition, including projectile activity, target hits, and whether a popup is open. This helps keep the controls and game behavior synchronized.
Interactive Popups
Each SVG target is associated with a different message. When a target is hit, JavaScript displays its message. The Go Back button closes the popup and returns the visitor to the game.
